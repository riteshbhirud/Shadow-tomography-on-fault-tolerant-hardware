[`measure`](@ref) runs one native measurement setting of a code on a logical stabilizer state and returns an [`OracleResult`](@ref) with one row per shot.

```julia
measure(code, setting_id, state; p, shots, seed=0, with_gap=true, params...)
measure(code, setting_id, state, p, shots; seed=0, with_gap=true, params...)
```

- `code` is `"surface"` or `"bb72"`.
- `setting_id` is `<operation>:<argument>`, e.g. `"local:XY"` or `"surgery:ZZ"`.
- `state` is a vector of `(label, sign_bit)` tuples, one per stabilizer generator of the logical state. Character i of a label acts on logical qubit i, and sign bit 0 means +1. `[("XX", 0), ("ZZ", 1)]` is the state with ``XX = +1`` and ``ZZ = -1``.
- `p` is the physical noise strength and `shots` the number of shots.
- `seed` seeds stim's sampler. The same circuit, `p` and `seed` give the same shots.
- `params` are the parameters of the operation, such as `d` and `memory_rounds`.

## The settings registry

`FTShadows.Circuits.REGISTRY` maps each code name to its native operations. An operation key ending in `*` matches every setting id with that prefix.

```@example manual
using FTShadows

for (name, pl) in FTShadows.Circuits.REGISTRY
    println(name, ": ", pl.describe, "; decoder ", pl.decoder)
    for (key, o) in pl.ops
        println("  ", key, " (", o.kind, "): ", o.describe)
        for (k, v) in sort(collect(o.params))
            println("      ", k, ": ", v)
        end
    end
end
```

The parameters and their defaults are tabulated on the [Conventions](@ref setting-ids) page.

## Surface code

Each logical qubit is one rotated surface-code patch of distance `d`. There are two kinds of settings.

- `local:B0B1…` with each ``B_i \in \{X, Y, Z\}`` measures patch i in basis ``B_i`` after `memory_rounds` noisy rounds. X and Z are measured by destructive readout of the data qubits. Y is measured with Gidney's in-place Y-basis measurement [gidney2024inplace](@cite), generated by his own code (see [Python dependencies](@ref python)).
- `surgery:ZZ` and `surgery:XX` measure ``Z_i Z_{i+1}`` (or ``X_i X_{i+1}``) of every pair of neighbouring patches by lattice surgery, for `rounds` merged rounds. After the merged rounds the patches are split and read out in the conjugate basis, so the product is learned from the merged rounds only.

```@example manual
bell = [("XX", 0), ("ZZ", 0)]
r = measure("surface", "local:XY", bell; p = 1e-3, shots = 1000, seed = 1, d = 3, memory_rounds = 3)
r.setting
```

The two strings `"XI"` and `"IY"` are measured on every shot. Their outcomes are the columns of `r.outcomes`:

```@example manual
size(r.outcomes), r.outcomes[1:3, :]
```

Lattice surgery measures the product directly:

```@example manual
r2 = measure("surface", "surgery:ZZ", bell; p = 1e-3, shots = 1000, seed = 1, d = 3, rounds = 3)
r2.setting, sum(1 .- 2r2.outcomes[:, 1]) / 1000
```

``\langle ZZ \rangle = +1`` for this state, so the mean is ``1 - 2q`` with q the flip rate of the setting.

At `p = 0` no decoder runs. The outcomes then follow the Born rule exactly. Here the state is the Bell state with ``ZZ = -1``:

```@example manual
r0 = measure("surface", "local:ZZ", [("XX", 0), ("ZZ", 1)], 0.0, 200; d = 3)
unique(r0.confidence_kind), sum(prod(1 .- 2r0.outcomes; dims = 2)) / 200
```

## The `OracleResult`

| field | content |
|:--|:--|
| `setting` | the Pauli strings measured jointly on every shot, one character per logical qubit |
| `outcomes` | shots × strings matrix of decoded bits; bit b means eigenvalue ``(-1)^b`` |
| `raw` | the same bits before the decoder's correction |
| `confidence` | one number per shot, the decoder gap, minimised over the strings; see [Decoders and the gap](@ref gap) |
| `confidence_kind` | what each confidence value means, one of [`CONF_KINDS`](@ref) |
| `cost` | the cost of the setting, the same for every shot; see [Costs](@ref costs) |
| `meta` | `p`, noise model, shots, decoder, seed, number of detectors and the experiment name |

```@example manual
r.meta
```

## BB72

BB72 is one block of 12 logical qubits. Its operations use one of two logical bases: the oracle basis for `readout` and `gauge`, and the local basis for `local`.

- `readout:X` and `readout:Z` read out all 12 logical qubits in X (or Z) by destructive readout of the 72 data qubits.
- `gauge:X0`, `gauge:Y0` and `gauge:Z0` measure ``\bar X_0``, ``\bar Y_0`` or ``\bar Z_0`` by the gauging measurement of Williamson and Yoder [williamson2024low](@cite), for `rounds` rounds. Only logical qubit 0 of the oracle basis is set up for it.
- `local:B0B1…` measures logical qubits ``0, \dots, m-1`` of the local basis, ``m \le 3``. The data qubits are read out in X or Z, whichever needs fewer extra qubits, and the qubits whose basis differs from the readout basis are gauged simultaneously beforehand, one gauging graph each.

The decoder is Relay-BP [muller2025improved](@cite). Its gap needs extra decodes, so this call takes about a minute:

```@example manual
rb = measure("bb72", "local:YZ", bell; p = 1e-3, shots = 100, rounds = 3)
rb.setting
```

```@example manual
[k => count(==(k), rb.confidence_kind) for k in unique(rb.confidence_kind)]
```

Shots of kind `not_found` have an unknown gap; see [Decoders and the gap](@ref gap). With `with_gap=false` only the predictions are computed (confidence `NaN`, kind `unavailable`), which is much faster on BB72.

```@example manual
rb.cost
```

## [Costs](@id costs)

Every result and record carries the cost of its setting as a dict:

| key | meaning |
|:--|:--|
| `merged_rounds` | noisy syndrome rounds of the setting; 0 for destructive readout. For surface local settings this includes the memory rounds and the rounds of the Y measurement |
| `extra_qubits` | qubits beyond the idle code blocks, which already have one syndrome ancilla per check; never negative |
| `circuit_layers` | layers in the noisy part of the circuit |
| `data_qubits`, `ancilla_qubits` | peak counts during the setting |
| `initial_data_qubits`, `initial_ancilla_qubits` | the idle code blocks |

In a surface `local` setting each patch is measured as soon as its own part of the circuit ends. In `local:XY` the X patch does not wait while the Y patch runs its extra rounds. The rounds and circuit layers of the setting are therefore the maximum over the patches, and the qubit counts are the sum over the patches.

```@example manual
r.cost
```

Here 6 merged rounds are the 3 memory rounds plus the 3 rounds of the d = 3 Y measurement (1 + b + 1 with b = 1 padding round). The surgery setting above has 3 merged rounds and 7 extra qubits:

```@example manual
r2.cost
```

## Per-shot records

[`records`](@ref) turns a result into one dict per shot, with the keys `setting`, `outcomes`, `confidence`, `confidence_kind`, `cost` and `meta`:

```@example manual
recs = records(r)
recs[1]["outcomes"], recs[1]["confidence"], recs[1]["confidence_kind"]
```

!!! warning "Not the dataset format"
    `records()` is not the dataset file format. Its dicts have no `shot` or `setting_id`, they carry `meta` on every shot, and the confidence is not rounded. Written with `FTShadows.write_records_raw`, an infinite confidence becomes `Infinity`, which is not valid JSON, and [`load_records`](@ref) refuses the file. [Shot records and datasets](@ref datasets) shows how to write files that the loaders read.

## Below `measure`

`measure` is `Circuits.build_setting` followed by [`run_oracle`](@ref). Calling the two directly gives access to the decoder and to the noise model:

```@example manual
using FTShadows: Circuits

exp, labels, decoder = Circuits.build_setting("surface", "surgery:ZZ", bell; d = 3, rounds = 3)
r3 = run_oracle(exp, 2e-3, 1000; decoder, seed = 2, setting_labels = labels, noise = "sd6")
r3.meta
```

`decoder` is a key of [`DECODERS`](@ref) and `noise` a key of `Circuits.NOISE_MODELS` ([Noise models](@ref noise)). `run_oracle` accepts any experiment for which [`oracle_circuit`](@ref) is defined.
