!!! warning "Logical level only"
    No shots are simulated here. The ensembles are evaluated as exact groups of logical Cliffords followed by an ideal destructive readout, and there are no shot records of them. The results are planning data for the choice of ensemble.

`FTShadows.TaskB` finds the logical Clifford operations that BB72, the gross code [bravyi2024high](@cite) and La-cross codes [difini2026fast](@cite) implement natively, the groups they generate, and the shadow norms of the resulting ensembles. The native operations are code automorphisms [sayginel2024fault](@cite), ZX-dualities and fold-transversal gates [breuckmann2024fold](@cite), and depth-one diagonal circuits [albert2026beyond](@cite); for the BB codes the logical basis is the f, g, h block basis of [bravyi2024high](@cite) (see also [eberhardt2024logical](@cite)).

All Paulis are rows ``(x|z)`` over GF(2) and Cliffords act from the right, ``v \mapsto vF``.

## Ensembles

An ensemble is "a uniformly random element g of a group G, a random logical Pauli frame, then destructive readout of all logical qubits in Z, in X, or in either with probability 1/2". For such an ensemble the shadow channel is diagonal in the Pauli basis [bu2022classical](@cite), with eigenvalue

```math
\lambda^Z_P = \Pr_{g \in G}[\, g P g^\dagger \text{ is Z-type} \,] = \frac{|\mathrm{orbit}(P) \cap \text{Z-type}|}{|\mathrm{orbit}(P)|},
```

and the squared shadow norm of P is ``\|P\|^2 = 1/\lambda_P``. P is learnable when ``\lambda_P > 0``. For the mixed readout, ``\lambda_P = (\lambda^Z_P + \lambda^X_P)/2``.

The ensembles are named in `TaskB.ENSEMBLES`:

| name | generators |
|:--|:--|
| `readout_only` | none: destructive all-Z or all-X readout only |
| `shifts` | the shift automorphisms ``x^a y^b`` (logical CNOT circuits) |
| `ibm` | shifts and the ZX-duality of [bravyi2024high](@cite) followed by transversal H |
| `aut` | all SWAP and H automorphisms: affine permutation automorphisms and ZX-dualities |
| `albert_two_fold` | `aut` and the Z- and X-diagonal matching circuits of all translates of the block-swap duality [albert2026beyond](@cite) |
| `aut_plus_all_folds` | `aut` and the Z- and X-diagonal circuits of every involutive ZX-duality whose circuit preserves the stabilizer group |

## Example

[`make_bb_code`](@ref) builds the code with its logical basis, and [`build_ensembles`](@ref) the candidate elements of every ensemble. Each element carries its physical gate list and its logical action, a ``2k \times 2k`` symplectic matrix (see [`logical_action`](@ref)).

```@example taskb
using FTShadows
import FTShadows.TaskB as TB

code = TB.make_bb_code("BB72")
code.n, size(code.lx, 1)
```

```@example taskb
ens, folds, info = TB.build_ensembles(code)
[name => length(ens[name]) for name in TB.ENSEMBLES]
```

[`channel_for_group`](@ref) labels the orbits of all ``4^{12}`` logical Paulis under the group generated by the logical actions and returns ``\lambda^Z`` and ``\lambda^X``. The generators need not be independent. A Pauli is packed as an integer v with its x bits in the low k bits and its z bits in the next k, and its entry is at index v + 1.

```@example taskb
k = 12
weight = TB.logical_weights(k)
for name in TB.ENSEMBLES
    λz, λx, _, labels = TB.channel_for_group([e.logical for e in ens[name]], k)
    λ = (λz .+ λx) ./ 2
    w1 = [λ[i] for i in eachindex(λ) if weight[i] == 1 && λ[i] > 0]
    println(rpad(name, 20), "orbits ", rpad(length(unique(labels)) - 1, 10),
            "learnable ", rpad(round(count(>(0), λ[2:end]) / (4^k - 1); digits = 4), 8),
            "weight 1: ", length(w1), "/36 learnable, min ‖P‖² ", minimum(1 ./ w1; init = Inf))
end
```

For comparison, random single-qubit Pauli measurements have ``\|P\|^2 = 3^{|P|}`` [huang2020predicting](@cite), which is 3 at weight 1.

## Group orders

[`group_order`](@ref) and [`reduce_generators`](@ref) need Oscar. They are implemented in the package extension `FTShadowsOscarExt`, which loads with `using Oscar`. Oscar is not a dependency of the main environment; the Task B scripts run in the small `scripts/oscar` environment:

```bash
julia --project=scripts/oscar -e 'using Pkg; Pkg.instantiate()'
julia --project=scripts/oscar scripts/taskb_run_all.jl
```

`taskb_run_all.jl` builds the groups of BB72 and the gross code, checks every kept generator against a QuantumClifford tableau simulation with signs, computes the shadow maps with [`shadow_map`](@ref), and runs the La-cross and basis-independence studies.

## La-cross codes

[`make_lacross_code`](@ref) builds the La-cross code of the seed ``H_{k,n}``, the hypergraph product of the seed with itself, in a generic CSS basis:

```@example taskb
lc = TB.make_lacross_code(3, 7)
lc.n, size(lc.lx, 1)
```

This is the ``[[65,9,4]]`` code of [difini2026fast](@cite). `TaskB.lacross(3, 7)` computes its automorphism and fold generators and their shadow statistics; group orders again need Oscar.
